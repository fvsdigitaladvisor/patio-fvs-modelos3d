# Pátio FVS — modelos 3D dos veículos

Modelos 3D (formato `.glb`) usados pela plataforma **Pátio FVS** (inspeção 3D de avarias para oficinas).
Cada pasta tem o arquivo `<chave>/<chave>.glb`.

Todos os modelos foram obtidos no [Sketchfab](https://sketchfab.com) sob a licença
[Creative Commons Atribuição 4.0 (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/),
que permite redistribuir com crédito ao autor. Os arquivos estão como foram baixados; a separação
das peças (portas, capô, para-lamas etc.) é feita pela plataforma no navegador.

Marcas, nomes e desenhos dos veículos pertencem aos seus fabricantes.
